# BuildsMine: duas instalações

Esta é a cópia independente para GitHub Pages e Antigravity. O BuildsMine do Codex é outro projeto, hospedado em https://casa-bambu-estudio.lucastraina.chatgpt.site/ .

Não há sincronização automática. Antes de copiar alterações entre os projetos, compare os históricos e os arquivos, preserve alterações locais e solicite a direção desejada. As mudanças enviadas a `main` neste repositório são compiladas pelo GitHub Actions e publicadas no GitHub Pages.

Para desenvolver: Node.js 22, `npm ci`, `npm run dev`; para validar, `npm run build`. O site é servido a partir da raiz do domínio GitHub Pages, pois várias rotas usam caminhos absolutos. O arquivo de configuração de hospedagem do Sites foi removido desta cópia para não associar o repositório GitHub ao projeto do Codex.

A Andorinha B permanece como construção principal. A amostra modular R1 está identificada como estudo não integrado, com imagens nativas e caderno.
