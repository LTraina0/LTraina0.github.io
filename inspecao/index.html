Dados construtivos

Os modelos do Ateliê usam o formato buildsmine.cells/1. Cada grupo de quatro números em cells descreve X, Y, Z e o índice em dictionary. A entrada correspondente de dictionary fornece ID Bedrock, estados e módulo. header contém parâmetros, limites, materiais e etapas. Os modelos anteriores usam uma lista blocks.

Inspeção com navegador

Após carregar o estúdio, execute window.BuildsMineInspector.snapshot() para consultar câmera, variante, componentes e erros. blocks() permite paginação até 256 células por consulta. controls() lista os controles. Os eventos buildsmine:ready e buildsmine:statechange sinalizam alterações observáveis.

WebMCP

Com suporte do navegador, a página registra buildsmine_inspect, buildsmine_controls, buildsmine_blocks, buildsmine_view e buildsmine_select. O registro detecta document.modelContext e navigator.modelContext. As ações operam a prévia na sessão atual. Clientes HTTP podem usar os JSONs estáticos diretamente.

Limites do acesso

Um erro Cache miss de um serviço de navegação não informa, por si só, o código HTTP do servidor. Caso esse serviço não consiga abrir este domínio, use um navegador com Chrome DevTools Protocol ou um cliente HTTP autorizado para consultar estes mesmos dados. A área de inspeção depende da entrega normal da hospedagem.
